# CMFtool

Illustrator 的 CMF 工具面板：編號標註 + Excel 規格表同步（在 Illustrator 裡改的字，包括表格裡的，存檔時也寫回 Excel），表格的序號和排列會跟著標註編號走；
標尺寸（物件的寬、高，圓的直徑 Ø，圓弧和圓角的半徑 R）；選一個標註或尺寸按「吸取樣式」，面板的樣式就改成跟它一樣；
也可以依某個物件的尺寸等比縮放整份文件（含工作區），或讓兩個物件互換位置和大小；
一次取代好幾組文字（含工作區名稱），快速換版本號和日期，日期、版本號可以自動填入。

安裝與使用方式見 [CMFTool/README.md](CMFTool/README.md)。
