# CMF Tool（Illustrator CEP 面板）

整合「CMF 標註」和「Excel 同步」：在產品圖上加編號標註、從 Excel 匯入規格表，
並讓表格的**序號和排列跟著標註編號走**。另外可以**標尺寸**（寬、高、直徑 Ø、半徑 R），
以及**依某個物件的尺寸等比縮放整份文件**。

## 安裝

1. 如果裝過舊版，先從 CEP extensions 資料夾刪掉 `com.cmf.callout` 和 `ExcelSync`。
2. 把整個 `CMFTool` 資料夾複製到：
   - Windows：`%APPDATA%\Adobe\CEP\extensions\`
   - macOS：`~/Library/Application Support/Adobe/CEP/extensions/`
3. 開啟未簽署擴充功能的除錯模式（只需做一次）：
   - Windows（命令提示字元）：
     ```
     reg add HKCU\Software\Adobe\CSXS.11 /v PlayerDebugMode /t REG_SZ /d 1 /f
     reg add HKCU\Software\Adobe\CSXS.12 /v PlayerDebugMode /t REG_SZ /d 1 /f
     ```
   - macOS（終端機），之後登出再登入一次，或執行 `killall cfprefsd`：
     ```
     defaults write com.adobe.CSXS.11 PlayerDebugMode 1
     defaults write com.adobe.CSXS.12 PlayerDebugMode 1
     ```
4. 重開 Illustrator，從「視窗 → 擴充功能 → CMF Tool」開啟。

## CMF 清單：表格依標註編號排序

Excel 規格表通常第一欄是序號、第二欄是物件名稱。

1. **Excel 分頁** → 匯入表格。
2. **CMF 清單 → 表格**：選這個表格。欄位預設是 A 序號、B 名稱，可以改。
3. **標註分頁**的編號表，每個編號後面多了下拉選單，選它對應的物件。
   第一次可以按「依序號對應」：每個編號自動對到 Excel 裡序號相同的物件。
4. 表格會依標註編號重新排列，序號欄改成標註編號。之後重新編號、互換號碼、
   把標註設為別的號碼，表格都會自動跟著改（「編號變更時自動排序」）。

- **同步修改 Excel 檔**（預設開啟，Windows）：Excel 檔案也一起依標註編號排序、改寫序號並存檔，
  跟在 Excel 裡手動排序一樣（用 Excel 的「排序」功能）。
  - **修改範圍**：Excel 檔只在這個範圍內排序、改序號，範圍外的儲存格完全不動。
    寫 `A3:F12`，或只寫欄 `A:F`（列跟表格相同）；留空 = 整個表格。範圍要包含序號欄和名稱欄。
    有合併儲存格跨出範圍時不會排序，結果欄會說明。
  - 列高不會改（跟 Excel 的排序一樣）；隱藏的列跟著內容移動。
  - Excel 開著這個檔案、而且還有其他未存檔的修改時，會排好但不自動存檔，留給你存。
  - 隱藏的列、設成「不顯示」的物件在 Excel 裡都會保留，排到後面、序號留空。
  - 透過外掛修改後，Excel 的「復原」無法還原這次排序。
  - 序號欄原本是公式（例如 `=ROW()-1`）時，會改成數字。
  - Mac 無法修改 Excel 檔，只會重排 Illustrator 裡的表格。
- 對應是記在標註上的物件名稱，所以重新編號、同步樣式之後，對應都還在。
- 一個物件只對應一個編號：把已經被用掉的物件選給別的編號，原本的編號會變成未對應。
- 未對應的物件排在最後，可以選「接續編號」、「序號留空」或「不顯示」。
- 標題列預設自動判斷（第一個序號是數字的列以上都算標題），判斷錯可以手動指定。
- 格式跟著列一起移動（填色、字型、色塊），跟在 Excel 裡排序一樣；
  上下框線留在原位，所以表格最下面的粗框線不會跑到中間。
- 資料列裡有上下合併的儲存格時無法排序，面板會說明是哪一列。
- Windows 透過 Excel 複製時，是在一個暫時的活頁簿裡排好再複製；
  公式會換成 Excel 顯示的值。開著「同步修改 Excel 檔」時，Illustrator 裡的表格就是照 Excel 原樣複製。
  Excel 無法複製或貼上失敗時（會自動重試），表格維持原樣，結果欄會寫原因；不會改用內建方式重畫。
- 名稱是空白的列（例如預留的空列）不算物件：放在最後，序號清空。

## 標註

按「新增標註」，工具會切到鋼筆。先點箭頭要指的位置，移動時會看到預覽線。

| 線條 | 操作 |
|---|---|
| 直線 | 點目標點 → 點編號位置 |
| 折線 | 點目標點 → 點轉折點 → 點編號位置 |
| 自由折線 | 左鍵持續加點，按「完成這條線」或快捷鍵完成（Ctrl/⌘ + 點空白處也可以） |

- 勾「連續」可以一直畫下去，按「結束新增」或 Esc 結束。
- 已經畫好的線（從產品畫向編號）選取後按「轉換線段」。
- 編號表：點一列選取並移過去；改數字後按 Enter，號碼已存在時兩個互換。
- 「樣式」裡的「同步全部」、「套用選取」、「重新排版」（移動線條錨點後讓編號重新對齊）。
  標註在鎖定、隱藏的圖層或群組裡也會更新，之後維持原本的鎖定、隱藏，也留在原本的群組裡；
  有標註無法更新時，狀態列會寫幾個、原因，其他的照常更新。
- 端點用「繪圖樣式」：在繪圖樣式面板建立 `CMF_Arrow`（或填入的名稱），可使用 Illustrator 內建箭頭。
  旁邊的 % 是繪圖樣式的線寬和箭頭要放大縮小多少；縮放文件時會自動跟著改（文件裡的繪圖樣式本身不會變）。
- 標註放在 `CMF Callouts` 圖層，每個標註是一個群組；圖層面板上會顯示「CMF 3 外殼」。

快捷鍵腳本（`CMF_新增標註.jsx` 等）照舊可用：它們透過 `com.cmf.callout.*` 事件和
`CMFCallout/settings.json` 跟面板溝通。

## 尺寸：寬、高、直徑 Ø、半徑 R

版面和操作方式參考 [Specees](https://specees.dazed.design)：

- **最上面的虛線框**是常用設定：`1:x` 圖面比例、單位、眼睛（數字後面加不加單位，閉眼 = 不加）、`.00` 小數位數；
  `Tt` 字級和文字顏色、線寬和線條顏色（顏色旁邊是滴管）。其他設定在下面的區塊。
- **中間的大按鈕**是「標尺寸」，四周的**圓點**選寬高標在哪一邊（藍色 = 開），右邊的**圖示**選要標什麼（亮起來、下面有藍線 = 開）。
- 在 Illustrator 選取物件後按「標尺寸」，一次標好。選好的類型和位置會記住，下次直接選物件按一下就好。

**類型**（右邊四個圖示，可以多選）：

| 按鈕 | 標什麼 |
|---|---|
| 選取範圍寬高（虛線框） | 選取的物件合起來的外框（延伸線 + 尺寸線 + 數字） |
| 各物件寬高 | 每個物件各自的寬高。兩個都開、只選一個物件時只標一次 |
| 直徑 Ø | 圓的直徑。選群組時，每種大小的圓標一個（一排同樣的孔只標一次） |
| 半徑 R | 圓弧、圓角的半徑。圓角矩形四個角一樣大時只標一個角 |

**位置**（「標尺寸」上下左右的圓點，可以多選）：上、下 = 標寬度，左、右 = 高度。例如只開「上」就只標寬度；上、下都開就兩邊都標。
直徑、半徑不看位置，方向由「直徑・半徑 → 角度」決定。沒有開寬高類型時，圓點會變淡。

- **距離**：寬高的尺寸線離物件多遠 (pt)。
- **寬高含線寬**：量到線條的外緣（跟「變形」面板勾「使用預視邊界」一樣）；不勾 = 只量形狀，不含線寬。
  剪裁群組都用遮色片的範圍。
- 寬高兩邊的箭頭放不下時（很窄的物件），箭頭改放在外面往內指；「樣式 → 箭頭位置」可以固定放內側或外側。
- **依物件大小自動調整樣式**：字級、線寬、箭頭、文字間距、延伸線、引線和「距離」跟著量的物件大小等比調整。
  - 「樣式」裡的數值是給**基準**大小（預設 100 mm）的物件用的：物件較長的一邊是 200 mm 就放大 2 倍、50 mm 就縮成一半；
    最多縮到一半，小零件的字才不會小到看不見。勾選後下面會顯示目前選取的物件會用幾倍、字級多大。
  - 寬高以量的範圍為準（同一次標的寬和高一樣大）；直徑、半徑以**選取的物件**為準，選整個產品群組標孔，
    孔的尺寸跟產品的寬高一樣大；只選一個小圓就照小圓的大小。
  - 標好之後，「樣式」的數值（和「距離」）會改成這個尺寸實際用的數值，基準也一起乘同一個倍率
    （例如 250 mm 的物件：字級 8 → 20、基準 100 → 250），所以看得到剛標的尺寸是什麼樣式，下一個物件照樣依大小調整。
  - 自動調整只在**新增**尺寸時作用。「同步全部」、「套用選取」會把尺寸都改成面板上目前的樣式，字級、線寬全部一樣大。

### 直徑・半徑

| 標法 | 樣子 |
|---|---|
| 引線拉到圓外（預設） | 箭頭從圓外指著圓周，引線往外拉，轉一段水平線，數字在線上 |
| 穿過圓心拉出去 | 直徑線（半徑從圓心）穿過圓、拉到圓外，箭頭往外指，數字在水平線上 |
| 畫在圓裡面 | 直徑線（半徑從圓心）畫在圓裡，數字在線旁邊或線中間 |
| 自動 | 放得下就畫在圓裡面，放不下（小圓、圓角）用引線 |

- **角度**決定直徑、半徑往哪個方向標：0° = 右、90° = 上、45° = 右上。
  圓角也是挑最靠這個方向的角，例如 135° 標左上角。
- **引線**：引線從圓周往外拉多長 (pt)；末端「字在線上」（數字站在水平線上）、
  「字在線後」（短水平線，數字接在後面）、「無橫線」（數字直接接在引線末端）。
- **半徑的圓心畫十字**：半徑畫在圓裡面或穿過圓心時，圓心畫一個十字。
- 只想標某一個圓角：用直接選取工具點那一段圓弧（或選它兩端的錨點），再按「半徑 R」。
- 同心圓（例如圓環的內外圈）一起標直徑時，最大的照常標，小的轉個方向、用引線拉到外面，數字不會疊在一起。
- 半圓以上的弧（例如長圓孔的兩端）也可以標直徑。
- 圓是看路徑的形狀判斷的：橢圓工具畫的正圓、圓角矩形和即時轉角都認得；橢圓、不規則的曲線不算。

### 數字和樣式

- **數字**：單位（mm、cm、in、pt、px 或文件單位）、最多幾位小數（尾數的 0 會去掉）、要不要加單位。
  **比例**是圖面比例：圖畫成實物的一半大就寫 `1:2`，標出來的數字乘 2。
- **符號**：直徑用 Ø、φ 或 ⌀。**數量**：群組裡有好幾個一樣大的圓時標成 `4×Ø3` 或 `4-Ø3`
  （圓角也一樣，例如圓角矩形 `4×R2`；直徑只數整圓，長圓孔兩端不算兩個）。
- **前後綴**：加在每個尺寸數字的前後，例如「約」、公差 `±0.1`、`(參考)`。
  前後綴是樣式的一部分，按「同步全部」時所有尺寸都會換成目前的前後綴；只想加在某幾個尺寸，選取它們按「套用選取」。
- **文字**：字級、顏色、字體；方向（沿著尺寸線或一律水平）；**擺放**在線的旁邊，或放在線的中間把線斷開
  （寬高、畫在圓裡面的直徑和半徑；線太短放不下時放在旁邊）；**底色**：文字後面墊一塊色塊，標在產品圖、照片上也看得清楚。
- **文字跟線的距離**（樣式 → 文字）：
  - **文字離線**：文字放在線旁邊時（包括引線橫線上的數字），文字跟線之間空多少 pt，從線的邊緣算，線寬不會吃掉距離。
  - **斷開留空**：文字放在線中間時，文字左右兩邊跟斷開的線頭之間空多少 pt（擺放選「線的中間」才能改）。
  - 改了之後，已經標好的尺寸要按「同步全部」或「套用選取」才會變（或勾「修改時自動套用到選取的尺寸」）。
- **線條**：線寬、顏色；端點（箭頭、開放箭頭、斜線、圓點、無）和大小；
  **箭頭位置**（寬高：自動、一律內側、一律外側）；**延伸線**跟尺寸線一樣粗、細一半或不畫，延伸線留空和超出的長度。
- 尺寸放在 `CMF Dimensions` 圖層，每個尺寸是一個群組（圖層面板上顯示「尺寸 120mm」），可以整個搬動、旋轉。
- **樣式**的「同步全部」讓所有尺寸套用目前的樣式、數字格式和直徑半徑的標法，「套用選取」只改選取的；
  尺寸的位置不變，搬過、轉過的也一樣。鎖定、隱藏的尺寸（或在鎖定、隱藏的圖層、群組裡的）也會更新，之後維持原本的鎖定、隱藏；
  有尺寸無法更新時，狀態列會寫幾個、原因，其他的照常更新。勾「修改時自動套用到選取的尺寸」，選取尺寸後改設定會馬上更新。
- 用**縮放分頁**縮放文件後，尺寸的數字自動改成縮放後的大小；尺寸分頁的字級、線寬、箭頭、文字離線、斷開留空、
  延伸線、引線、「距離」和自動調整的「基準」也一起縮放，之後新增的尺寸跟縮放後的一樣大（縮放分頁的「標註、尺寸的樣式設定也跟著縮放」）。
- 尺寸不會跟著物件變：物件改了大小，刪掉舊的尺寸重新標。
- 數字是一般的文字物件，可以直接改字；但按「同步全部」、「套用選取」或縮放文件時會重新產生。
- 直徑符號 Ø（U+00D8）、φ（U+03C6）、⌀（U+2300），字體裡沒有這個字時請換字體或換符號（⌀ 比較少字體有）。

## Excel 同步

- 面板會自動找 .ai **同一個資料夾**裡的 Excel（有好幾個時優先用同名的），也可以按「選擇…」。
- **綁定文字**：選取文字物件，輸入 `B3` 或 `工作表1!B3`，按「綁定」。綁定資訊存在物件名稱（`xl:B3`）。
- **匯入表格**：輸入 `A1:D10`，或留空使用 Excel 中選取的範圍。
  - Windows：請 Excel 直接複製，外觀和手動複製貼上完全一樣（會用到剪貼簿）。
  - Mac，或 Excel 無法使用時：外掛讀取樣式自己畫（不支援條件式格式設定、文字旋轉）。
- Excel 改完存檔後按「從 Excel 更新」，或勾「存檔時自動更新」。表格會保留位置和縮放。
- 表格由 Excel 控制：在 Illustrator 裡改表格樣式，下次更新會被蓋掉。

## 縮放：依物件尺寸縮放整份文件

選一個物件、輸入它想要的寬度或高度，整份文件（物件、文字、線寬、效果、工作區）一起等比縮放：
看起來跟原本一樣，只有尺寸改變。

1. 在 Illustrator 選取一個物件（選好幾個時，以它們合起來的外框為準）。
2. **縮放分頁**會顯示它目前的寬高。在「目標」輸入寬度或高度，另一邊和比例會自動算出來；
   也可以直接輸入比例。數字後面可以加單位（`150mm`、`15cm`、`6in`），沒寫就是文件的單位。
3. 選範圍，按「縮放」（或在欄位裡按 Enter）。
   - **物件所在的工作區**：只縮放這個工作區和上面的物件，工作區左上角不動；
     其他工作區、不在這個工作區上的物件都不變。放大後蓋到別的工作區時，狀態列會提醒。
   - **全部工作區**：所有工作區和文件裡所有物件（包含工作區外面的）一起縮放。

- 寬高的算法跟「變形」面板一樣：有勾「使用預視邊界」就含線寬；剪裁群組用遮色片的範圍。
- 線寬、效果、圓角、圖樣、漸層都跟著縮放，不管偏好設定裡「縮放線條和效果」有沒有勾。
- 鎖定、隱藏的圖層和物件也會縮放，縮放完維持原本的鎖定、隱藏。
- 畫面的顯示比例也跟著調整，所以縮放完畫面上看起來沒有變化，用「變形」面板就能看到新的尺寸。
- 物件屬於哪個工作區：看它跟哪個工作區重疊最多。群組會整個一起縮放，
  所以跨好幾個工作區的群組（例如整頁群組起來）也會整個縮放。
- 標註記錄的字級、線寬、間距等也跟著改，之後重新編號、重新排版都維持縮放後的大小。
- 尺寸的數字改成縮放後的大小，字級、線寬也跟著縮放。
- **標註、尺寸的樣式設定也跟著縮放**（預設勾選）：縮放後，標註分頁「樣式」裡的字級、線寬、端點大小、
  繪圖樣式的 %、間距、圓圈內距和邊框，尺寸分頁的字級、線寬、箭頭、文字離線、斷開留空、延伸線、引線和「距離」
  都乘上同一個比例。之後繼續新增標註、尺寸，大小跟縮放後的一樣，不用重新設定。兩種範圍都會縮放。
  - 只縮放一個工作區時，其他工作區的標註、尺寸沒有縮放；這時按「同步全部」，它們也會換成縮放後的大小。
    只想更新這個工作區的，選取它們按「套用選取」，或縮放前取消勾選這個選項。
  - 取消勾選：面板的樣式設定維持原本的數值（文件裡的標註、尺寸照樣縮放）。
- Excel 表格會保留縮放後的大小，之後「從 Excel 更新」照樣保留。
- 工作區最大約 5779 mm（Illustrator 的上限），放大後超過時不會縮放。

### 交換兩個物件的位置和大小

在縮放分頁下面。選取兩個物件（圖片、群組都可以），按「交換選取的兩個物件」：
A 換到 B 的位置、變成 B 的大小，B 換到 A 的位置和大小。

- **保持比例**（預設）：兩個比例不同時，放進對方的範圍裡、置中，不會變形。
  取消勾選 = 寬高完全換成對方的（比例不同時會拉伸）。
- 大小的算法跟「變形」面板一樣；剪裁遮色片的圖片以遮色片的範圍為準。線寬跟著縮放。
- 只換位置和大小，圖層和上下順序不變。
- 兩個物件在同一個群組裡時，用群組選取或直接選取工具選。

## 數字欄位和中文輸入法

面板上的數字欄位（字級、線寬、編號、尺寸、縮放的寬高等）在中文輸入法開著時也能直接打數字，
不用切回英文：游標在數字欄位裡時，輸入法不會啟動。
- ↑↓ 一次加減一格（Shift 一次 10 格）；數字欄位只接受數字、小數點和正負號。
- 在數字欄位裡打字時，按鍵（包括數字鍵台、Backspace、Ctrl+V）只給面板，不會傳給 Illustrator 去移動或刪除選取的物件。
- 全形數字會自動換成半形。
- 要打中文的欄位（Excel 的工作表名稱、繪圖樣式名稱）照常使用輸入法。
