# CMF Callout — Illustrator CEP 插件

把線段一鍵轉成「編號 + 引線 + 端點」的 CMF 標註。

## 安裝

1. 開啟未簽署擴充功能的除錯模式（只需做一次，CSXS 版本 9–12 都設比較保險）
   - macOS：`defaults write com.adobe.CSXS.11 PlayerDebugMode 1`（把 11 換成 9、10、12 各執行一次）
   - Windows：登錄檔 `HKEY_CURRENT_USER\Software\Adobe\CSXS.11` 新增字串值 `PlayerDebugMode` = `1`（同樣 9–12 都加）
2. 把整個 `com.cmf.callout` 資料夾放到：
   - macOS：`~/Library/Application Support/Adobe/CEP/extensions/`
   - Windows：`%APPDATA%\Adobe\CEP\extensions\`
3. 重開 Illustrator，從「視窗 > 擴充功能 > CMF Callout」開啟面板
4. 除錯：Chrome 開 `http://localhost:8088`

## 使用方式

### 新增標註

按「新增標註」（或用快捷鍵），工具會自動切到鋼筆。先點箭頭要指的位置，移動滑鼠時會看到預覽線。

| 線條模式 | 操作 |
|---|---|
| 直線 | 點目標點 → 點編號位置（第 2 下自動完成） |
| 折線 | 點目標點 → 點轉折點 → 點編號位置（第 3 下自動完成） |
| 自由折線 | 左鍵持續加點，按面板上的 **「完成這條線」** 或快捷鍵完成（Ctrl/⌘ + 點空白處也可以） |

- 沒勾「連續新增」時，完成後會自動切回選取工具
- 有勾的話可以一直畫下去，按「結束新增」或在面板上按 Esc 結束
- 自由折線畫到一半就按「結束新增」，已經點下的部分（至少 2 點）也會轉成標註

> 右鍵在 Illustrator 裡會開啟右鍵選單，CEP 插件偵測不到，所以自由折線用「完成這條線」按鈕或快捷鍵確認。建議把 `CMF_完成折線.jsx` 設成 F 鍵，畫完直接按。
> 開啟智慧型參考線（⌘U / Ctrl+U），目標點會吸附到產品的錨點和邊緣。

### 轉換已畫好的線

用鋼筆或線段工具**從產品畫向編號位置**，全部選取後按「轉換選取的線段」。

### 編號表

- 列出文件中所有編號，以及每個編號用了幾處
- 點一列：選取該編號的所有標註，並把畫面移過去
- 改數字後按 Enter：若新號碼還沒用過就直接改；若已經存在，兩個號碼會互換
- 在畫布上刪除或複製標註後，把滑鼠移回面板，表格會自動更新

### 樣式同步

- **同步全部標註的樣式**：文件中所有標註套用面板目前的線條與文字樣式
- **修改下方樣式時自動同步全部**：勾選後，調整字級、顏色、線寬等設定，畫面上的標註會即時跟著變
- **套用到選取**：只改選取的標註
- **重新排版選取**：用直接選取工具移動線條錨點後，讓編號重新對齊

標註會放在 `CMF Callouts` 圖層，每個標註是一個群組。同步或改號時，標註會依照線條重新產生；如果手動移動過數字，請改為移動線條的錨點。

### 端點用「繪圖樣式」

腳本無法直接設定描邊的箭頭樣式。若要用 Illustrator 內建箭頭：
畫一條線、在描邊面板設好箭頭，到繪圖樣式面板新增樣式並命名為 `CMF_Arrow`（或面板中填的名稱）。
之後修改這個繪圖樣式，就能一次改到所有標註。

### 字體

從「字體」和「字重」選單選擇，清單讀取自 Illustrator 已安裝的字體。第一次開啟面板時會掃描一次並快取，安裝新字體後請按「重新讀取」。

## 快捷鍵

`scripts/` 裡有三支獨立腳本：

- `CMF_新增標註.jsx`：開始／結束互動新增（面板需要是開啟狀態，收合在旁邊也可以）
- `CMF_完成折線.jsx`：自由折線模式下，完成目前正在畫的線
- `CMF_轉換標註.jsx`：轉換選取的線段（使用面板最後一次的設定）
- `CMF_重新編號.jsx`：重新編號

放到 Illustrator 的 `Presets/<語系>/Scripts/` 資料夾並重開。在「動作」面板新增動作，從選單選「插入選單項目」，選擇「檔案 > 指令碼 > 這支腳本」，然後指定 F 鍵。

## 檔案結構

```
com.cmf.callout/
├── CSXS/manifest.xml
├── .debug
├── index.html        面板介面與預覽
├── jsx/host.jsx      ExtendScript 核心邏輯
└── scripts/          快捷鍵用的獨立腳本
```
